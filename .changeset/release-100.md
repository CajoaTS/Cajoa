Cajoa 1.0. The API in the docs is now stable and follows semantic versioning. There are no code changes since 0.21.0. The experimental parts (the `Renderer` interface, `ServerContext` and the hydration markers) are listed on the Stability page. Requires Node.js 20 or newer, and Vite 8 for the plugin.
