# @cajoa/core

The renderer-agnostic core of [Cajoa](https://github.com/CajoaTS/Cajoa): signals, effects, JSX runtime, `Show`, `For`, context, and the `Renderer` interface.

Most apps should install [`cajoa`](https://www.npmjs.com/package/cajoa) instead. Use this package directly when you build a custom renderer.
